Lasse Wingreen — public career pages
Updated 29 October 2026

index.html is the public career overview. It contains professional experience,
a link to the public CV and PDF download, and contact details. It does not list
private applications or name their recipients.

cv.html is the public CV. Lasse-Wingreen-CV.pdf is the existing two-page PDF.
The iPaper experience is historical and shown through 2026. The precise
contractual end date still needs confirmation before a later CV revision.

The Manrope font is served from ../assets/fonts/manrope-latin.woff2.
style.css controls the career pages and their browser print layout. site.js
only enables the Print button. Public content and PDF downloads work without JS.

Private application source and build tools are kept outside the website,
in the wingreen-redesign/private folder. Use the private build tooling to
regenerate encrypted documents. Do not copy plaintext application files,
password files or legacy content/build files into this public website folder.
